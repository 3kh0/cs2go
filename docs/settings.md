# Settings and live match menu

Settings fills the content area beneath the homepage navbar, using the native dark Panorama page treatment and compact rows with right-aligned controls. In a live match it fills the viewport and continues the simulation. Escape or the close control dismisses it; homepage navigation can switch away directly. Settings has keyboard-accessible Video, Audio, Gameplay, Controls and Crosshair tabs. Existing sensitivity, FOV, volumes, HUD hue, graphics preset, bunnyhop, key bindings remain saved under `cs2go-settings`.

Video adds an unlimited or 30–360 FPS render cap and 50–100% resolution scale within the existing graphics preset's framebuffer budget. Simulation continues stepping at 128 Hz independently of skipped render frames. Texture High retains full source resolution; Medium and Low upload half and quarter dimensions using existing compressed mip levels or resized bitmap textures. Switching back to High restores source images. Filtering uses up to 8× / 4× / 1× anisotropy, limited by hardware. This reduces GPU texture detail/memory, not asset download size or retained source memory. Baked lightmaps, shader data textures and reflection targets are preserved. Newly applied first-person skins receive the selected quality within one second.

Crosshair settings include independent color, length, thickness, gap, opacity, center dot, black outline and dynamic movement/firing expansion, with an immediate preview. Scope hiding remains unchanged.

Escape releases pointer lock and clears held movement/fire inputs. It opens an unblurred live scoreboard beneath a compact native-style pause navbar at 96 UI units from the top. Resume Game, Inventory, Settings and Disconnect use neutral translucent surfaces, condensed labels and the native white hover treatment. Local-only navigation omits server votes/reports and team-switch actions that the game does not implement. Bots, reloads, utility, round/buy/bomb timers and player gravity continue; players remain vulnerable. Settings and skin menus also leave an active match running. Browser-hidden tabs still suspend work. Returning to the main menu ends the local match.

Browser coverage: `bun run test:browser tests/settings-tabs.spec.ts tests/control-settings.spec.ts`. Screenshots are written under ignored `artifacts/`.
