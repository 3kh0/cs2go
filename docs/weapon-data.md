# Weapon and economy data

The weapon snapshot was fetched from the current `SteamTracking/GameTracking-CS2` master HEAD on 2026-10-12, commit `5278de99318192d682ec7f0e1cc3ea9449f10c6e` (2026-10-11). This repository tracks shipped Valve game files; it is not Valve's open source engine. Values are a pinned snapshot, not a claim that future live patches remain identical.

- [weapons.vdata](https://github.com/SteamTracking/GameTracking-CS2/blob/5278de99318192d682ec7f0e1cc3ea9449f10c6e/game/csgo/pak01_dir/scripts/weapons.vdata): gun prices, kill awards, damage, armor ratio, head multipliers, magazine sizes, reserve units, range, attenuation, penetration, running speeds, cycle/reload durations, pellet count/spread, scope levels.
- [Competitive configuration](https://github.com/SteamTracking/GameTracking-CS2/blob/5278de99318192d682ec7f0e1cc3ea9449f10c6e/game/csgo/cfg/gamemode_competitive.cfg) and [casual configuration](https://github.com/SteamTracking/GameTracking-CS2/blob/5278de99318192d682ec7f0e1cc3ea9449f10c6e/game/csgo/cfg/gamemode_casual.cfg): round/kill rewards, start/cap money, buy/freeze/round times, friendly fire factors, free armor and kits.
- [items_game.txt](https://github.com/SteamTracking/GameTracking-CS2/blob/5278de99318192d682ec7f0e1cc3ea9449f10c6e/game/csgo/pak01_dir/scripts/items/items_game.txt): item definitions 50/51/55 list kevlar $650, armor+helmet $1000, defuser $400; weapon prefabs list faction availability.
- [Console defaults](https://github.com/SteamTracking/GameTracking-CS2/blob/5278de99318192d682ec7f0e1cc3ea9449f10c6e/DumpSource2/convars.txt): maximum loss level 4, loss aversion enabled, C4 40 seconds, default round restart 7 seconds (casual overrides to 10).

Regenerate `apps/game/src/data/weapon-stats.json` with `python3 scripts/import-weapon-stats.py` (Python 3 and curl). It downloads the pinned file with TLS verification and extracts the named weapon blocks. The JSON stores its source, commit and SHA-256; runtime never fetches upstream files. Run the project formatter after regeneration. Inventory IDs 0–11 remain stable; the other 25 firearms append at IDs 12–36.

Notable differences from older CS:GO references: AWP 5 rounds, M4A1-S 20, M4A4 $2900, MP7/MP5-SD $1400, CZ75-Auto kill award $300, XM1014 kill award $600. The planted-and-defused T team bonus is $600 competitive/$200 casual. Competitive starts at loss level 1 ($1900 first loss), decays by one on wins and caps at $3400. A surviving terrorist gets no timeout loss award. Casual has $1000 start/$10000 cap and competitive $800/$16000.

Valve explicitly documents discarded remaining rounds in its [magazine reload update](https://www.counter-strike.net/newsentry/532126482488623360). `m_bReserveAmmoAsClips` is true for all magazine-fed firearms in this snapshot. `m_nPrimaryReserveAmmoMax` counts whole magazines for those guns. Runtime reserves retain bullet-equivalent display units, but a reload discards the remaining current magazine and spends a full spare. Nova, XM1014 and Sawed-Off retain individual shell reserves; MAG-7 uses magazines.

The shared armor reconstruction applies weapon armor ratio / 2 to protected health damage and spends half the absorbed damage as armor points. Head protection requires a helmet; legs ignore armor. An exhausted vest can absorb only twice its remaining armor points. Both bots and the human use the same function. Standard hit regions use weapon-specific head multiplier, chest/arms 1×, stomach 1.25× and legs 0.75×. This formula and the hit hulls are a reconstruction, not extracted Source 2 executable logic. The shipped weapon armor ratios are directly imported. Heavy armor is not implemented.

Recoil now uses separately imported seeds/parameters and a researched deterministic generator; see [recoil provenance](recoil-provenance.md) for the distinction between shipped inputs and reconstructed runtime behavior. Animation retiming, knife attack behavior and body/material thickness remain approximations. `m_flDisallowAttackAfterReloadStartDuration` now supplies reload durations directly in seconds; cosmetic playback no longer stretches this gameplay clock. `m_flDeployDuration` gates attacks after switching independently of the visual draw clip; a ready attack interrupts the remaining draw pose. Glock/FAMAS use shipped burst spacing (0.05/0.075 seconds) and first-shot cycle deadlines (0.5/0.55 seconds), preserved through switching. Per-level `m_flZoomTime0/1/2` drives FOV transition duration, using a reconstructed linear interpolation rather than a claim about native easing. Native sound and reload markers follow the same normalized reload timeline. Shell intro/outro retiming remains reconstructed. Magazine ammo commits at the imported `WPN_RELOAD_ADD_AMMO` marker (including the empty Deagle variant), normalized onto the pinned reload clock; missing markers fall back to completion. Holstering after that marker retains the new magazine and spent spare, while the original reload readiness deadline and the next draw/deploy delay still gate firing. Holstering before it cancels without transferring ammo. Source spray patterns, revolver trigger mechanics and all animation timings are not established by this numeric snapshot.

## Native map triggers

`python3 scripts/import-buy-zones.py --vpk /path/to/de_dust2.vpk --cli /path/to/Source2Viewer-CLI` extracts `func_buyzone` and `func_bomb_target` entities and collision hulls from the same October 8 Dust II VPK used for rendering. `apps/game/src/dust2-buy-zones.json` records entity/model identifiers, original planes, depot version and hashes. The importer verifies all eight vertices and six planes form axis-aligned boxes before reducing them to bounds; arbitrary brushes are not silently replaced by bounding boxes.

The native buy zones, in Source coordinates/inches, are T `[-1196,-1016,0]` to `[-312,-632,288]` and CT `[-192,1984,-128]` to `[592,2560,-32]`. The runtime applies the same Source-to-Three transform as the map and tests physical hull overlap, including partial entry and vertical separation. The current browser actor uses a 0.3-meter half-width and current collision height; that hull and edge-contact behavior remain emulations. The trigger geometry itself is imported exactly. [Valve's public trigger-contact code](https://github.com/ValveSoftware/source-sdk-2013/blob/master/src/game/server/baseentity.cpp) supports collision-property contact rather than testing only the feet point, but is not the closed current CS2 engine.

A site preserves two separate native trigger boxes, including its excluded corner and different heights; B has one. Both players and bots use their union when planting. Buy time, faction and living-round checks remain separate from geometric membership.
