# Combat fidelity and evidence

Weapon draw presentation uses the loaded native clip duration divided by the shared 0.9 playback rate. Gameplay lockout independently uses shipped `m_flDeployDuration`; a ready shot cancels any remaining draw presentation. Reload attack readiness uses the shipped delay without dividing it by the cosmetic playback rate. Native sound events follow their animation clock.

R8 primary fire requires 0.234375 seconds of continuous trigger hold (30 simulation ticks); release, switch and reload cancel preparation. Preparation overrides a previous shot's visual tail, and starting preparation cancels inspection. Secondary fire is immediate, uses its native shoot2 clip/cycle time and the pinned alternate spread of 0.068. Cocking time is a Source-style reconstruction, not a measurement of the current proprietary CS2 runtime. The raw prepare animation is normalized to that trigger phase; unlike draw clips, it is not used as the firing delay.

Knife attacks distinguish front initial/repeated slash (40/25), front stab (65), rear slash (90) and rear stab (180). Knife armor penetration is 85%, including armor depletion. Head/limb multipliers do not apply. Rear attacks use the victim's facing cone; slash/stab reach is 48/32 Source units. Miss/hit recovery is 0.4/0.5 seconds for slash and 1/1.1 seconds for stab. Impact phases remain reconstructed. Center traces cannot attack through walls; a narrow four-ray fan provides forgiving edge contacts when the center misses, approximating a melee hull. These values follow the historical Source knife implementation; current CS2 knife parity has not been independently measured.

Mechanical audio is bundled directly from the pinned October 22 CS2 depot: Butterfly draw and all three inspect variants, general knife draw/contacts and revolver preparation. Regenerate with `python3 scripts/import-cs2-effects-audio.py`, then `python3 scripts/pack-audio.py`. Native event mappings and hashes are in `packages/assets/public/audio/cs2-effects-source.json`; see [audio provenance](weapon-audio.md). The supplied knife GLBs omit sound events, so opening/catch offsets are authored reconstructions, not extracted event timings. Firearm GLBs retain native normalized event times.

Gunplay imports per-weapon, per-mode standing/crouching, movement, airborne, ladder, firing and intrinsic-spread inputs from the pinned shipped `weapons.vdata` snapshot. Regenerate using `python3 scripts/import-accuracy-data.py`; `packages/simulation/src/data/accuracy.json` records the source URL, commit and SHA-256. The runtime interpolates stance using actual duck height, and movement penalties begin above 34% of the weapon's mode-specific maximum speed and reach full strength at 95%. Counter-strafing therefore regains resting accuracy before horizontal speed reaches exactly zero. These movement thresholds and the radial spread distribution follow legacy Source conventions; the combination is reconstructed, not a measurement of the current CS2 executable.

Firing adds the weapon's accuracy penalty **after** resolving the bullet. Each weapon recovers continuously and independently, including while holstered, rather than waiting on a shared timer and reducing an abstract shot count. Shipped recovery endpoints interpolate with recoil index and crouch posture; the reconstructed exponential law removes 90% of the penalty over one recovery interval. Intrinsic spread and inaccuracy are independently sampled radial cones, for both player and bots. Shotguns apply intrinsic pellet spread once. Bot aiming error is a separate angular offset shared by pellets in a shot, so dispersion no longer depends on world-axis orientation. Scoped bot rifles use their aiming mode; visible bot scope handling remains simplified.

Accuracy now retains posture/mode baseline penalties through transitions, recovering toward a lower baseline rather than deleting them on landing or zoom. Airborne posture uses standing accuracy, with four times base crouched recovery; movement uses the historical fourth-root curve except while walking. Landing adds the shipped mode coefficient times downward Source-unit velocity. Jump dispersion uses pinned initial/apex endpoints with the historical square-root vertical-speed curve. Combining the newer nonzero Deagle apex endpoint with that older curve is an explicit reconstruction; current CS2's apex interpolation is unknown. The authored 0.18-second scope accuracy timer was removed: scope mode settles through ordinary baseline recovery, separately from camera zoom timing.

R8 secondary uses the historical inverted-square radius distribution; its primary retains ordinary radial sampling. The first three Negev recoil indices use historical repeated-square/inversion transforms. Each trigger pull samples one shared inaccuracy offset, with intrinsic spread sampled separately for every pellet before hit effects can consume random numbers. These are historical implementation references, not verified native CS2 shot seeds. The pinned current convar dump enables fixed shotgun patterns; their current generator remains unknown and is not reproduced. Ladder/stack coefficients are supported by the accuracy API, but gameplay has no traversable ladder or multi-level boost-stack tracking. Current recoil integration, native random seeds, fixed shotgun patterns, remaining actor hitboxes and native subtick processing remain unverified. See `recoil-provenance.md` for the evidence boundary.

Ground Rebel (T) bullet collisions now use its 19 native bone-local capsule hitboxes, including native damage-group IDs, rather than decorative/skinned triangles and a guessed head sphere. Both player-on-T and bot-on-T fire trace the same animated capsules. The importer verifies the model's SHA-256 and equality of all four embedded `cstrike` sets from the existing agent manifest (game version **25000182**, distinct from the weapon-data snapshot). Regenerate using `python3 scripts/import-agent-hitboxes.py --cli /path/to/Source2Viewer-CLI`; imported units remain Source inches because the preserved native bone rig already carries its 0.0254 world conversion. Nearest capsule entry determines the damage region and overlapping capsules still count as one actor through the existing penetration solver.

The IDF CT mesh is a legacy community port and has not been assigned Ground Rebel's capsules. Player-on-CT intersections retain its animated mesh with bone-relative head/torso classification; bot-on-CT and bot-on-player retain simplified volumes. Flesh penetration thickness is still approximated. The imported T capsule definitions are verified source data; current-CS2 equivalence across all agent models, animation poses and server hitbox updates has not been established.

Validation: `apps/game/src/melee.test.ts` covers damage/armor, facing cones and reach; `apps/game/src/accuracy.test.ts` covers pinned posture/mode values, counter-strafe thresholds, continuous independent recovery and radial spread. `apps/game/tests/accuracy.spec.ts` verifies actual first/second bullet dispersion and holstered recovery. `apps/game/tests/combat.spec.ts` exercises loaded draw durations, R8 input lifecycle and knife mechanical cue dispatch, with screenshots in ignored `artifacts/`.

`apps/game/src/soldier-hitboxes.test.ts` covers capsule cylinder/endcap intersections, misses, origins inside, rotation invariance and degenerate capsules. `apps/game/tests/native-hitboxes.spec.ts` checks loaded native head bones in standing/crouched poses and produces an ignored debug-overlay screenshot for visual alignment review.
