# Browser player collision

Horizontal movement continuously sweeps the axis-aligned square player hull against map triangles clipped to the actor's feet/head interval. Separating-axis entry/exit intervals determine the earliest contact over the complete displacement, including zero-thickness triangles. After advancing just before contact, inward velocity is removed along that plane and the remaining time slides along the surface, with at most four contacts per segment.

Grounded movement retains bounded subdivisions to sample stair/ramp support. Each segment uses the continuous sweep; collision correctness no longer depends on endpoint overlap or sampling a sufficiently short displacement. Grounded step-ups still require a walkable surface within 18 Source units and clearance at both ends. Airborne movement never steps up. Initial overlap from vertical/posture changes still uses the bounded local contact resolver; no radial free-space search or teleport across nearby walls is used.

This is a continuous **horizontal** hull sweep against the imported static triangle collision map, not a full native CS2 3D swept-hull implementation. Vertical support, ceilings, crouch hull changes and landing retain the existing browser implementation. Source's entire player-movement algorithm and dynamic prop physics are not reproduced.

Regression coverage includes fast travel into zero-thickness walls from both sides, tangential velocity retention, a concave angled seam followed by retreat, tangent travel across triangulated face seams, ramps, steps, low ceilings, standing/crouched hulls, and native imported geometry browser tests. Run `bun run test src/map-collision.test.ts` and `bun run test:browser tests/slopes.spec.ts tests/bin-collision.spec.ts`. The native T-spawn bin test crosses the lids toward the bag pile and retreats along six nearby paths, checking for a valid hull and successful retreat. The exact original reported stuck trajectory was not reproduced; this covers the pictured location and the collision failure class rather than claiming an exact reproduction.

Local native Dust II microbenchmark (October 13, 2026): 1,010 non-overlapping supported start positions around T-spawn bins, twenty directional movement samples each, five paired warm trials. The previous endpoint resolver's median was 61.570 ms for 20,200 moves (3.05 µs/move); the continuous sweep's median was 82.613 ms (4.09 µs/move). Both ended with zero invalid hulls. This measures collision calls in Bun on this machine, not complete browser frame time. Swept triangle AABB rejection reduced the first unoptimized implementation's approximately 281 ms batch cost substantially. Hot-path clipping uses shared typed-array scratch buffers and vectors, with no per-contact allocations.
